# 읽기 쉬운 글 — 보드 노드 모달이 읽는 칸

보드의 노드 모달은 난독증 사용자도 읽도록 짰다(글자와 여백만, 16px, 줄 간격 1.7, 번호·약어 없음). 화면이 아무리 좋아도 글이 길고 약어투성이면 읽지 못한다. 모달은 아래 칸을 그대로 가져다 보이므로, 쓰는 쪽이 이 규칙을 지킨다.

| 칸 | 쓰는 법 | 모달에서 |
|---|---|---|
| 노드 브리프 `## 문제` | 글머리 항목 1~4개. 항목마다 한 문장, 40자 안팎. 글머리 없이 한 문단을 쓰면 그 통째가 한 줄로 나와 길다 | 「왜 했나」 |
| 결정 행 `title` | 질문 한 문장 | 「정한 것」의 질문 |
| 결정 행 `options[].label` | 그 글만 읽어도 뜻이 통하는 한 문장. "A안"·"추천대로" 같은 말은 쓰지 않는다 — 선택지 글자와 번호는 모달에 나오지 않는다. 안 고른 선택지는 모달에 나오지 않는다 | 「정한 것」의 고른 답 |
| 작업 행 `given`·`when`·`then` | 각각 한 문장. 주어를 적는다. 영문 약어와 내부 코드는 처음에 한글로 풀어 쓴다 | Given · When · Then |
| 노드 브리프 `## 완료 기준` | `- [ ]` 항목마다 검사 하나. runner가 만족한 항목을 `- [x]`로 바꾼다 | 「완료 기준」 |
| `evidence/<노드 키>/*.png` | 파일 이름이 그림 이름표가 된다(확장자 뺌). `fix-1`·`before-목록`처럼 무엇인지 보이게 짓는다. 확인 대기가 아니어도 보인다 | 그림 |

## 문장 규칙

- 한 문장은 40자 안팎. 한 덩어리는 한 가지 일만 말한다. 긴 문장은 목록으로 쪼갠다.
- 약어·영문 코드는 처음 나올 때 한글로 푼다. 내부 번호(D7·P1·n9·T9)는 문장 안에 넣지 않는다 — 모달에 번호가 나오지 않아 무슨 말인지 모른다.
- 이탤릭·밑줄·전부 대문자는 쓰지 않는다. 강조는 굵게 한 곳에만.
- 명령·경로는 백틱으로 짧게. 문장 한가운데 긴 명령을 넣지 않는다.
- 모달에서 이미 보이는 것은 쓰지 않는다: 앞뒤 노드 이름, 항목 개수, "3건" 같은 세는 말.
